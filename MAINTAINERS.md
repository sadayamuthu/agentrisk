## Wanted

AgentRisk has one maintainer, and wants more, especially from organizations
not already represented. Areas where help would make the biggest difference:

- the factor definitions and scoring specification,
- the calibration study against public incidents,
- parsers for more agent configuration formats,
- dashboard and inventory integrations.

If you're interested, start with an issue labelled `good first issue` or
`help wanted`, or open an issue to say what you'd like to work on.
